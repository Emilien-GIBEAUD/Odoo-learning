Gestion de livre :

Livre
├── titre
├── auteur ───────────┐
├── année             │ Many2one
└── description       ▼
                    Auteur
                    ├── nom
                    ├── date de naissance
                    ├── nationalité ──┐
                    └── biographie    │ Many2many
                                      ▼
                                    Nationalité
                                    └── nationalité
  • Create → créer un(e) livre/auteur/nationalité
  • Read → afficher la liste et le détail
  • Update → modifier un(e) livre/auteur/nationalité
  • Delete → supprimer un(e) livre/auteur/nationalité
